계산 방법

물성 데이터 출처

  • 기체 CO, CO2, O2, N2: Cantera gri30.yaml (NASA 7계수 다항식, 이상기체)
  • 고체 탄소: Cantera graphite.yaml 의 C(gr), 활동도 1
  • 엔탈피는 생성엔탈피를 포함한 절대값 h_i(T) 를 쓰므로 반응열을 따로 더하지 않습니다.
  • 표준 Gibbs 에너지: g°_i(T) = h_i(T) − T·s°_i(T, 1 bar)
  • 상수: R = 8.314 J/(mol K), F = 96485 C/mol, p° = 1 bar, LHV_C = 393.5 kJ/mol

Cantera를 직접 부르는 곳은 thermo_init.m, sp_h.m, sp_s0.m 세 파일뿐입니다. legacy 문법(set, enthalpy_mole, entropy_mole)을 먼저 시도하고, 실패하면 실험적 toolbox 문법(gas.TPX, gas.H)으로 넘어갑니다.

부호 규약

  • Q > 0: 장치로 들어가는 열, Q < 0: 빼내는 열
  • W > 0: 장치로 들어가는 전력 (SOFC는 수지표에서 W = −W_cell)
  • 원소 잔차 = Σ(원자 in) − Σ(원자 out), 에너지 잔차 = ΣH_in + Q + W − ΣH_out
  • 보고용 P_in, P_out, 방출열은 양수로 표기

식

Boudouard   K_B(T) = exp(−ΔG°_B/RT) = (p_CO2/p°)/(p_CO/p°)²,   ΔG°_B = g°_C + g°_CO2 − 2g°_CO
셀          E_rev = −ΔG°_ox/2F + (RT/2F)·ln[(p_CO/p°)(p_O2/p°)^½/(p_CO2/p°)]
            V_ch = E_rev + 0.10,  V_dis = E_rev − 0.10,  I = 2F·ṅ_CO,  W_cell = I·V
분리기      W_sep = ṅ_CO2,23·R·T_sep·ln(1/x_CO2,15),  방출열 = W_sep
압축기      W_comp = ṅ_air·R·T0·ln(P/P0),  방출열 = W_comp
열교환기    Q_max = min[H_h(T_h,in) − H_h(T_c,in), H_c(T_h,in) − H_c(T_c,in)],  Q = ε·Q_max
thermal link  donor(Q<0)가 receiver(Q>0)보다 20 K 이상 뜨거울 때 Q_link = min(0.85·|Q_donor|, Q_receiver)
효율        η_ch = N_C·LHV_C/E_in,  η_dis = E_out/(N_C·LHV_C),  η_RT = E_out/E_in = η_ch·η_dis

솔버 절차

재순환 루프는 반복 계산 없이 해석해로 풉니다.

충전 (Stream 2의 CO, CO2를 a, b, 탄소 석출량을 ξ)

  • 혼합기 CO 수지: ξ = 0.35b, CO2 수지: 0.7b = 1 + ξ → ξ = 1, b = 20/7 kmol/s
  • 반응기 출구 CO2는 c = 13/7 kmol/s로 고정, 재순환 CO는 평형으로 결정: a = c·[1 + √(1 + 4K_B·P/p°)]/(2K_B·P/p°)

방전 (Stream 15의 CO, CO2를 a, b, 탄소 소비량 ξ = 1)

  • 분리기 CO 수지: a = 0.2(a + 2ξ) → a = 0.5, Stream 18의 CO = m = 2.5 kmol/s
  • Stream 18의 CO2는 평형으로 결정: c = m·[−1 + √(1 + 4K_B·P/p°)]/2, b = c + ξ
  • 공기: 양론 O2 = 1 kmol/s, 공급 O2 = 3 kmol/s, N2 = 3·79/21 kmol/s

조성이 정해지면 에너지수지를 장치 순서대로 계산합니다. 온도 미지수(혼합기, 열교환기 출구)는 fzero 로 H(T) = H_target 을 풉니다. 열교환기는 내부 21개 지점에서 T_hot − T_cold > 0 을 확인합니다.

왕복 효율과 운전 시간

같은 탄소 재고를 쓰도록 N_C = ṅ_C,ch·t_ch = ṅ_C,dis·t_dis 로 맞춥니다. 과제 유량(둘 다 1 kmol/s)에서는 t_dis = t_ch 입니다.

맞추지 않은 전력의 비 P_out/P_in 은 두 모드의 탄소 처리 속도를 어떻게 잡느냐에 따라 달라집니다. 방전 속도만 2 kmol/s로 올리면 전력 비는 0.446으로 2배가 되지만, 같은 재고가 절반 시간에 소진되므로 에너지 비는 0.223 그대로입니다. main.m [1] 끝에서 이 예를 계산합니다.

개선 방향 요약

  1. 열교환기 유용도 향상과 공기 과잉률 축소: H3 부하(78 MW)와 배기 손실을 직접 줄입니다. 민감도가 가장 큽니다.
  2. 저압 운전 또는 배기 팽창기 추가: 압축 전력 57 MW를 회수 없이 버리는 것이 방전 손실의 큰 몫입니다.
  3. 충전 반응기 발열(171 MW, 650 °C) 활용: Stream 3 예열(H1 74 MW)에 쓰거나, 반응기 온도를 셀보다 높여 link를 살립니다.
  4. 셀 온도를 link 경계 근처까지 낮추기, 셀 전압 손실 저감.
  5. SOFC 잔여 방출열(87 MW, 850 °C)로 H3, H2, Trim 가열을 대체합니다.
