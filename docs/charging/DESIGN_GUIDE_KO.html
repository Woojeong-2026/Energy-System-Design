Charging 담당 설계·검산 가이드

1. 담당 범위와 산출물

과제의 charging 담당은 CO₂ → C(s)+O₂의 정상상태 공정 모델, 에너지 부하와 개선안을 설계합니다. 탄소는 저장하고 O₂는 25°C까지 냉각한 뒤 밸브로 대기에 방출합니다. 산소 판매/저장 에너지나 방출열에 효율 credit을 주지 않습니다.

3. 손계산으로 고정할 물질수지

F=nCO2,1, X=Xsoec, a=nCO,2, b=nCO2,2, ξ=nC,10로 둡니다. 단위는 kmol/s.

SOEC:       nCO,5 = a + Xb           nCO2,5 = (1−X)b
            nO2,12 = Xb/2
반응기:     nCO,7 = a + Xb − 2ξ     nCO2,7 = (1−X)b + ξ
재순환:     n7 = n9
혼합기:     a = a + Xb − 2ξ         b = F + (1−X)b + ξ
따라서:     ξ = F                   Xb = 2F
            b = 2F/X                c ≡ nCO2,7 = b−F

기준값은 ξ=1, Xb=2, b=20/7, c=13/7입니다. 전체 생성 O₂도 1 kmol/s입니다. CO₂를 한 번만 전환하는 70%와 전체 탄소 회수율을 혼동하지 마십시오. 완전 재순환·무퍼지 정상상태에서는 신선 공급 탄소가 모두 저장됩니다.

ΔG°B(T) = g°C + g°CO2 − 2g°CO
K_B = exp(−ΔG°B / RuT)
K_B = [yCO2·P/p°] / [yCO·P/p°]²
    = c(a+c) / [a²(P/p°)]
k = K_B(P/p°)
a = c[1 + sqrt(1+4k)]/(2k)

흑연의 활동도는 1이고 고체 유량은 기체 몰분율 분모에 포함하지 않습니다. 충전 반응의 총 몰수는 보존되지 않으므로 총 몰유량 보존을 검사하면 안 됩니다. 보존량은 C/O/N 원자 또는 질량입니다.

기준 독립 계산: K_B=3.10242931, a=0.53517546 kmol/s, yCO,7=0.22370579.

4. 전기화학과 열부하

E0 = −(g°CO2 − g°CO − 0.5g°O2)/(2F_Faraday·1000)
Erev = E0 + (Ru·Tcell)/(2F_Faraday·1000)
                ·ln[(pCO,5/p°)sqrt(pO2,12/p°)/(pCO2,5/p°)]
Vch = Erev + 0.10
I_equiv = 2F_Faraday·1000·Xb = 4F_Faraday·1000·F
Wcell = I_equiv·Vch

여기서 F_Faraday=96485 C/mol, Ru=8314 J/(kmol K)입니다. kmol→mol 변환을 누락하면 전류·전력이 1000배 틀립니다. I_equiv=385.94 MA는 1 kmol/s 탄소 기준 전체 활성 셀의 합산 등가 전류입니다. 단일 stack의 단자전류를 정한 값이 아닙니다. 직렬 셀 수와 병렬 stack, 전류밀도가 있어야 실제 전압·전류·면적을 배분할 수 있습니다.

Hk = Σ ni,k hi(Tk)로 계산하고, 생성엔탈피를 포함한 Cantera 엔탈피를 사용합니다. 별도의 반응열을 다시 더하지 않습니다.

장치 장치로 들어가는 열 Q [W]
Heater H1 H4−H3
SOEC H5+H12−H4−Wcell
Trim 5→6 H6−H5
반응기/고체 분리기 H7+H10−H6
재순환 냉각기 H9−H8
탄소 냉각기 H11−H10
산소 냉각기 H13−H12

Vtn=(H5+H12−H4)/I. 기준값 Vtn≈1.46210 V > Vch≈1.14918 V이므로 SOEC는 흡열(+120.769 MW)입니다. 전압 손실은 이미 Vch에 들어갔으므로 별도의 I·0.10 V 열손실을 다시 더하지 않습니다. 히터/trim의 Q가 음수가 되는 변형 조건도 가능하므로 부호대로 냉각으로 분류해야 합니다.

5. 열교환·열회수 검산

Qmax,h = H(n7,TB) − H(n7,T2)
Qmax,c = H(n2,TB) − H(n2,T2)
Qhex   = ε·min(Qmax,h,Qmax,c)
H8     = H7 − Qhex           H3 = H2 + Qhex

반응열/화학엔탈피를 회수열로 혼동하지 않도록 각 유체의 같은 조성으로 온도만 바꿔 Qmax를 구합니다. 상수 cp 근사를 쓰지 않고 엔탈피를 역산해 T₃와 T₈을 얻습니다. 향류의 같은 위치는 저온 입구 끝에서 Hcold=H2+q, Hhot=H8+q입니다. 201점에서 Thot−Tcold>0를 검사하고 HEX 전체 엔트로피 생성률도 음수가 아닌지 확인합니다. 샘플링은 연속 구간의 엄밀한 최소화 증명이 아닙니다. 최소 온도차가 작아지는 개선안은 격자 세분화/최소화와 실제 설계 여유를 추가하십시오.

thermal link는 다음을 모두 만족해야 합니다.

  1. donor의 원래 Q<0, receiver의 원래 Q>0.
  2. donor 온도−receiver 온도≥20 K.
  3. 경로가 셀↔Boudouard 반응기.
  4. Qlink=min(0.85·|Qdonor|,Qreceiver).

기준 충전에서 반응기 650°C→셀 850°C는 2번을 만족하지 않습니다. 171 MW의 반응열이 있어도 셀 전기가열에서 뺄 수 없습니다. 잔여 양의 부하는 100% 전기 저항 가열, 잔여 음의 부하는 방출입니다. HEX 열은 이미 H3/H8에 반영되었으므로 Pin에서 다시 빼면 이중 계산입니다.

MATLAB 검증기의 원소 허용오차: 1e−9 + 1e−8·max(abs(n)) kmol/s. 에너지 허용오차: 0.1 + 1e−8·max(abs(Pin),abs(Q),1) W. 온도 지정값 허용오차는 1e−5 K, 압력 1e−4 Pa입니다. 이들은 계산 검증 허용오차이며 제작 공차/안전계수가 아닙니다.

수지표의 에너지 잔차가 0인 것만으로 충분하지 않습니다. Q를 엔탈피 차로 정의했으면 틀린 모델도 스스로 수지를 닫을 수 있습니다. 그래서 평형·스트림 지정·전류·열전달 방향과 독립 계산을 함께 검사합니다. Cantera의 25°C 반응 엔탈피와 과제의 반올림된 LHV=393.5 kJ/mol은 미세하게 다릅니다. 에너지 닫힘에는 실제 엔탈피 차, 보고용 효율에는 지정 LHV를 쓰십시오.

8. 개선안과 추가 장치 설계의 경계

  • 우선 비교할 개선안: HEX 유용도 변화, SOEC 전환율 변화, 충전 반응기 온도 변화. 탄소 처리량과 공통 시스템 조건을 고정해 비교합니다.
  • TB,ch=870°C에서는 Tcell=850°C와 20 K 차로 link가 가능해질 수 있습니다. 동시에 CO 재순환량과 장치 크기 부담이 커집니다. 열회수 증가만 보지 말고 Pin·ηch·순환량·최소 온도차를 함께 제시합니다.
  • 반응기 열로 H1을 예열하는 추가 경로는 과제의 기본 셀↔반응기 link에 포함되지 않습니다. 개선 제안으로 별도 공정도·온도 구간·열수지를 정의해야 합니다.
  • 충전 기간의 잔열을 방전 기간으로 넘기는 계산은 기본 과제에서 허용되지 않습니다. 열저장 장치를 새로 설계하는 대안이라면 기준 결과와 분리해야 합니다.
  • 실제 HEX 면적은 U·LMTD 또는 ε–NTU와 형상/압력강하가 필요합니다. Q만으로 확정할 수 없습니다.
  • 실제 반응기 체적은 반응속도·체류시간·전달현상·고체 배출 설계가 필요합니다. 평형 도달 가정만으로 체적을 정할 수 없습니다.
  • 셀 총 활성면적의 시작식은 A_total=I_equiv/j입니다. 과제는 전류밀도 j나 stack 구성을 주지 않아 수치 설계값을 임의로 넣지 않았습니다.

발표용 권장 구성: ①충전 공정/경계 ②물질수지·평형 유도 ③스트림표 ④열부하·전력/회수 분리 ⑤검산 잔차·HEX T–Q ⑥압력/온도 스윕 ⑦개선안과 통합 효율.
