충전 프로젝트 시작

기존 팀 프로젝트와 충전 코드·검산·발표 자료가 모두 들어 있는 폴더입니다. 파일을 복사해서 합치거나 복원 코드를 실행할 필요가 없습니다.

충전 계산 실행

  1. MATLAB에서 이 폴더의 main_charging.m을 엽니다.
  2. 위쪽의 초록색 Run ▶을 누릅니다.
  3. 현재 폴더를 바꾸라는 창이 나오면 Change Folder를 선택합니다.

계산 결과는 이 폴더 안의 results/charging_review/에 저장됩니다. 전체 충전·방전·왕복 효율 계산은 main.m을 실행합니다.

계산에 필요한 프로그램: MATLAB R2026a와 Cantera 3.0.0 MATLAB toolbox. 이 폴더에는 상용 MATLAB과 Cantera 설치 프로그램이 포함되어 있지 않습니다. Cantera가 설치·경로 등록되어 있지 않으면 먼저 해당 환경 설정이 필요합니다.
